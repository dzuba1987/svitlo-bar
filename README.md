# SvitloBar

Графік відключень світла (АТ «Вінницяобленерго») у рядку меню macOS.

## Встановлення

1. Завантажте `SvitloBar.zip` з [останнього релізу](https://github.com/dzuba1987/svitlo-bar/releases/latest) і розпакуйте.
2. Перенесіть `SvitloBar.app` у теку «Програми» (Applications).
3. Перший запуск: правий клік на додатку → «Відкрити» → «Відкрити» (додаток не підписаний сертифікатом Apple).
   Або в Терміналі: `xattr -dr com.apple.quarantine /Applications/SvitloBar.app`
4. Вкажіть адресу в налаштуваннях — черга визначиться автоматично.

Працює на macOS 13+ (Apple Silicon та Intel).

## Оновлення

Додаток сам перевіряє нові релізи кожні 6 годин. Коли є нова версія, у меню з'явиться
«⬆️ Встановити оновлення» — додаток завантажить її та перезапуститься.
Перевірити вручну: меню → «Перевірити оновлення».

## Для розробника

- `./build.sh` — зібрати й встановити локально.
- Кожен push у `main` автоматично збирає додаток і публікує реліз (GitHub Actions),
  версія підіймається сама: 1.1 → 1.2 → 1.3… Опис релізу = повідомлення коміту.
- `./release.sh "що змінилось"` — коміт + push одним рядком.
- Нова «велика» версія: впишіть її у `VERSION` (напр. `2.0`) — далі піде 2.1, 2.2…
- Зміни лише README не створюють реліз.
